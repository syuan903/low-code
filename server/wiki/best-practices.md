# 问卷设计最佳实践（Best Practices）

设计高质量问卷时，请遵循以下原则：

## 1. 开头清晰
- 在问卷开头使用 `text-note` 写明问卷标题与一段简短的欢迎语，说明问卷目的、预计耗时和数据用途，提升填写意愿。

## 2. 题量适中
- 题目数量保持适中（一般 5~12 题为宜），过长会显著降低完成率。
- 每道题只问一件事，避免"双重问题"（一句话里包含两个问题）。

## 3. 选项设计
- 选项之间应互斥（mutually exclusive），不重叠。
- 选项应尽量穷尽（exhaustive），必要时增加"其他"或"以上都不是"。
- 单选题选项不宜过多，超过 6 个考虑改用 `option-select` 下拉。

## 4. 题序安排
- 先易后难：先放简单、轻松、封闭式的问题，建立填写节奏。
- 由浅入深：先问行为/事实，再问态度/观点。
- 敏感问题（收入、隐私、个人信息）尽量靠后，避免一开始就引起抵触。

## 5. 语言中立
- 题干与选项用词中立，避免引导性、暗示性表述。
- 措辞简洁明了，避免专业术语与歧义。

## 6. 结尾
- 可在结尾使用 `text-note` 表达感谢，或说明后续事项。
