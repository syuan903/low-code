# 常见问卷范式（Survey Patterns）

以下为常见问卷主题的典型题型组合，供出题时参考。实际题目可在此基础上裁剪增删。

## 满意度调研（Satisfaction Survey）
- text-note：标题与欢迎语（说明本次满意度调查目的）
- rate-score：整体满意度评分
- rate-score：各维度评分（如服务、质量、价格）
- single-select：是否愿意再次使用 / 推荐意愿
- multi-select：最满意的方面
- text-input：改进建议（开放题）

## 消费习惯调查（Consumption Habits）
- text-note：标题与欢迎语
- single-select：消费频率
- multi-select：常购买的品类
- option-select：单次消费金额区间
- single-select：主要消费渠道（线上/线下）
- multi-select：影响购买决策的因素
- text-input：其他补充

## 个人信息收集（Demographics）
- text-note：标题与隐私说明
- single-select：性别
- option-select：年龄段 / 学历 / 职业
- date-time：出生日期
- text-input：联系方式（靠后放置）
- 提示：个人信息属敏感内容，应放在问卷靠后位置。

## 活动报名 / 反馈（Event）
- text-note：活动标题与说明
- text-input：姓名
- date-time：可参加时间
- single-select：是否首次参加
- multi-select：感兴趣的环节
- rate-score：往期活动评分（如适用）
- text-input：备注

## 产品使用反馈（Product Feedback）
- text-note：标题与欢迎语
- single-select：使用时长
- multi-select：常用功能
- rate-score：易用性评分
- single-select：是否遇到问题
- text-input：问题描述与建议
